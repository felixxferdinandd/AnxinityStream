Panduan Penggunaan AnxinityStream

Solusi komprehensif bagi streamer 1 monitor untuk membaca chat YouTube & TikTok sekaligus saat bermain game.

1

Menghubungkan YouTube Live

Cukup salin link siaran langsung YouTube kamu (contoh: https://youtube.com/watch?v=xxxx) atau masukkan handle channel (contoh: @NamaChannel). Klik Sambungkan. Kolom otomatis terkunci saat aktif.

2

Menghubungkan TikTok LIVE (100% Bebas Login)

Masukkan username TikTok kamu (contoh: mooniyelle). Tidak perlu login, tidak perlu password, dan tidak butuh API key. Aplikasi langsung terhubung via WebSocket.

3

Menggunakan Ghost Mode (Hotkey: F9)

Pindahkan jendela chat overlay ke sudut layar game yang nyaman. Buka game kamu (disarankan mode Borderless Windowed). Tekan F9 untuk mengunci overlay menjadi tembus klik kursor mouse!

4

Mengatur Opacity Langsung di Overlay

Di header atas jendela chat overlay, tersedia slider mini transparansi langsung. Kamu bisa menggesernya secara realtime tanpa perlu alt-tab ke menu kontrol!
